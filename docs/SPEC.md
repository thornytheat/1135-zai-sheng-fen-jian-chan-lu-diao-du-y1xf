# 再生料班次契约

磅单保留原编号，时间以 UTC 处理。吨转换为公斤后只允许整数。计量坏行、重复扫描、晚到更正、同版冲突各自归因。料批的材质与产线须一致才能进入取样。

抽检上中下三个层位。各层按称样重量加权，跨层采用等权。Wilson 上界是调度参考提示。每个切片的等效样本数取 10，现场部署需按抽样方案估计有效样本数。无取样或缺层影响放行。

按材料拟合岭回归，特征为入料量对数、杂质比例、水分比例与涡电流线标识。训练统计来自已关账的历史折，估值界为留出误差的保守分位。严重超出历史支持时输出留样复验。

干净物料依据保守产率下界预留公斤数。同材质仓位采用可完整容纳的最小剩余空间优先。班次限额按 1 吨计。预留、未分配预计出料与预计残渣之和应等于地磅净重，逐批和逐仓核对。

## 环节分组诊断

每个环节公开分组、风险方向与阈值、有效观测数、缺测数和命中的凭证。只有有限数值计入诊断，等于阈值的记录保持正常。相关证据计数与明细逐项守恒。诊断随 API 和证据导出提供。
